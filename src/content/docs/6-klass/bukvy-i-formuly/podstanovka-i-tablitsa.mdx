Датчик передаёт число $x$, а программа вычисляет $3x-2$. Один вход даёт один выход. Если подать несколько входов по очереди, получится таблица, которая показывает зависимость результата от $x$.

## Подстановка — точная замена

Вместо каждой буквы ставим указанное число, лучше сначала в скобках. Для $3x-2$ при $x=-1$ запись шага выглядит так:

$$3\cdot(-1)-2=-3-2=-5.$$

Скобки помогают увидеть, что минус относится ко всему числу $-1$.

  client:visible

  mode="table"
  variables={[{ name: 'x', label: 'Значение x', initial: 0, min: -5, max: 5, step: 1 }]}
  tableVariable="x"
  tableValues={[-2, -1, 0, 1, 2, 3]}

/>

Полученная таблица содержит пары

$$(-2;-8),\ (-1;-5),\ (0;-2),\ (1;1),\ (2;4),\ (3;7).$$

В каждой паре сначала записан вход $x$, после точки с запятой — значение выражения. Если увеличить $x$ на $1$, выход увеличивается на $3$.

<Concept type="rule" title="Алгоритм подстановки">
  1. Замени каждую букву её значением, отрицательное число заключи в скобки.
  2. Выполни действия в обычном порядке.
  3. Проверь знак и примерный размер ответа.
</Concept>

<WorkedExample title="Две переменные">
  Найдём $2a-3b$ при $a=-1{,}5$ и $b=2$:

  $$2\cdot(-1{,}5)-3\cdot2=-3-6=-9.$$

  Значения разных букв подставляются независимо. Нельзя заменить $b$ числом, заданным для $a$.
</WorkedExample>

## Не всякое число подходит

Это небольшое углубление готовит язык 7 класса. Сейчас достаточно одного арифметического ограничения: деление на ноль невозможно.

Рассмотрим выражение

$$\frac{12}{n-1}.$$

При $n=3$ знаменатель равен $2$, результат равен $6$. При $n=1$ знаменатель становится нулём, а делить на ноль нельзя. Поэтому $1$ — недопустимое значение для этого выражения.

<Concept type="remember" title="Допустимые значения">
  Значение переменной допустимо, если после подстановки все указанные действия можно выполнить. В частности, ни один знаменатель не должен стать нулём.
</Concept>

## Таблица — не набор несвязанных ответов

Таблица позволяет увидеть, как меняется выход. Для $y=3x-2$ постоянная разность соседних выходов равна $3$, если соседние входы отличаются на $1$. Но это наблюдение верно только при одинаковом шаге по $x$.

<Concept type="mistake" title="Минус перед отрицательным числом">
  В выражении $5-x$ при $x=-2$ получается $5-(-2)=7$, а не $3$. Сначала запиши подстановку со скобками, затем используй правило вычитания отрицательного числа.
</Concept>

<Concept type="remember" title="Квадрат — короткая запись произведения">
  В двух заданиях ниже встретится $x^2$. Здесь $x^2=x\cdot x$: число умножают само на себя. Никакие другие правила действий со степенями в этом уроке не нужны.
</Concept>

## Практика

1. Найди $4x+1$ при $x=2$.
2. Найди $4x+1$ при $x=-2$.
3. Найди $5-a$ при $a=-3$.
4. Найди $x^2-1$ при $x=-4$.
5. Найди $2p+q$ при $p=1{,}5$ и $q=-2$.
6. Заполни выходы для $y=2x-3$, если $x=-2;-1;0;1;2$.
7. Запиши пары $(x;y)$ из задания 6.
8. На сколько меняется $y=5x+4$, когда $x$ увеличивается на $1$?
9. Вычисли $\frac{18}{m+2}$ при $m=1$.
10. Какое значение недопустимо для $\frac{7}{k-4}$?
11. Найди ошибку в подстановке: $-2x=-2-3=-5$ при $x=3$.
12. Составь таблицу для $a^2$ при $a=-2;-1;0;1;2$. Что замечаешь?

<details>
  <summary>Ответы и пояснения</summary>

  1. $9$.
  2. $-7$.
  3. $5-(-3)=8$.
  4. $(-4)^2-1=16-1=15$.
  5. $2\cdot1{,}5+(-2)=1$.
  6. $-7;-5;-3;-1;1$.
  7. $(-2;-7)$, $(-1;-5)$, $(0;-3)$, $(1;-1)$, $(2;1)$.
  8. На $5$.
  9. $\frac{18}{3}=6$.
  10. $k=4$, потому что знаменатель стал бы нулём.
  11. Запись $-2x$ означает умножение: $-2\cdot3=-6$.
  12. Значения $4;1;0;1;4$; противоположные входы дают одинаковые квадраты.

</details>

## Итог

- Подстановка заменяет букву числом, но не меняет порядок действий.
- Таблица собирает пары «вход; выход» и помогает увидеть зависимость.
- Перед вычислением нужно убедиться, что значение допустимо.

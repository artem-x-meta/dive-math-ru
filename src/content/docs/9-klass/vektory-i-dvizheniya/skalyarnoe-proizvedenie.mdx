Два троса тянут баржу из точки $O$: один в направлении $(4;3)$, другой — в направлении $(3;-4)$. Под каким углом они расходятся?

Транспортира нет, чертёж приблизителен. Зато есть координаты — и одна операция, которая вытаскивает из них угол.

## Прогноз до вычислений

Векторы $\vec a(4;3)$ и $\vec b(3;-4)$ имеют одинаковые длины. Посмотри на их координаты и попробуй сказать, какой между ними угол — острый, прямой или тупой.

Запиши догадку. Через минуту у нас будет способ ответить точно.

## Управляемый эксперимент

Меняй координаты и следи за знаком числа $\vec a\cdot\vec b$ и за видом угла на чертеже.

Знак меняется ровно в тот момент, когда угол проходит через $90°$. Это не совпадение.

## Определение

<Concept type="rule" title="Скалярное произведение">
  **Скалярным произведением** ненулевых векторов $\vec a$ и $\vec b$ называют число

  $$\vec a \cdot \vec b = |\vec a|\cdot|\vec b|\cdot\cos\alpha,$$

  где $\alpha$ — угол между векторами, отложенными от одной точки. Если хотя бы один вектор нулевой, произведение считают равным нулю.
</Concept>

Обрати внимание на слово «число». Результат операции — не вектор. Именно поэтому произведение называют скалярным: скаляр — это величина без направления.

<Concept type="rule" title="В координатах — короче">
  Если $\vec a(x_1;y_1)$ и $\vec b(x_2;y_2)$, то

  $$\vec a \cdot \vec b = x_1x_2 + y_1y_2.$$

  Перемножаем одноимённые координаты и складываем. Ни длин, ни косинуса для этого знать не нужно.
</Concept>

Отсюда сразу следует важный частный случай — **скалярный квадрат**:

$$\vec a \cdot \vec a = x_1^2+y_1^2 = |\vec a|^2.$$

Свойства операции похожи на привычные: $\vec a\cdot\vec b = \vec b\cdot\vec a$, затем $(k\vec a)\cdot\vec b = k(\vec a\cdot\vec b)$ и $(\vec a+\vec b)\cdot\vec c = \vec a\cdot\vec c + \vec b\cdot\vec c$.

## Знак произведения и вид угла

Длины всегда положительны, поэтому знак произведения полностью определяется знаком $\cos\alpha$:

- $\vec a\cdot\vec b > 0$ — угол острый (или нулевой, если векторы сонаправлены);
- $\vec a\cdot\vec b = 0$ — угол прямой;
- $\vec a\cdot\vec b < 0$ — угол тупой (или развёрнутый, если векторы противоположно направлены).

<Concept type="rule" title="Признак перпендикулярности">
  Ненулевые векторы перпендикулярны тогда и только тогда, когда их скалярное произведение равно нулю:

  $$\vec a \perp \vec b \iff x_1x_2+y_1y_2 = 0.$$
</Concept>

Теперь вернёмся к прогнозу: $\vec a(4;3)$ и $\vec b(3;-4)$ дают $4\cdot3 + 3\cdot(-4) = 12-12 = 0$. Тросы расходятся ровно под прямым углом — и для этого не понадобилось ни одного измерения.

## Угол между векторами

Из определения выражаем косинус:

$$\cos\alpha = \frac{\vec a\cdot\vec b}{|\vec a|\cdot|\vec b|} = \frac{x_1x_2+y_1y_2}{\sqrt{x_1^2+y_1^2}\cdot\sqrt{x_2^2+y_2^2}}.$$

<VecDotLab client:visible mode="angle" initialAx={1} initialAy={2} initialBx={3} initialBy={1} challenge={true} />

<WorkedExample title="Угол по координатам">
  Найдём угол между $\vec a(1;2)$ и $\vec b(3;1)$.

  Скалярное произведение: $\vec a\cdot\vec b = 1\cdot3 + 2\cdot1 = 5$.

  Длины: $|\vec a| = \sqrt{1+4} = \sqrt5$, $|\vec b| = \sqrt{9+1} = \sqrt{10}$.

  $$\cos\alpha = \frac{5}{\sqrt5\cdot\sqrt{10}} = \frac{5}{\sqrt{50}} = \frac{5}{5\sqrt2} = \frac{1}{\sqrt2} = \frac{\sqrt2}{2}.$$

  Значит $\alpha = 45°$ — здесь ответ оказался точным, без округления.
</WorkedExample>

<WorkedExample title="Все углы треугольника по вершинам">
  Даны $A(1;2)$, $B(5;2)$, $C(1;5)$.

  **Угол $A$.** Векторы $\vec{AB} = (4;0)$ и $\vec{AC} = (0;3)$, их произведение $4\cdot0+0\cdot3 = 0$. Значит $\angle A = 90°$.

  **Угол $B$.** Векторы $\vec{BA} = (-4;0)$ и $\vec{BC} = (-4;3)$, произведение $16+0 = 16$. Длины: $|\vec{BA}| = 4$, $|\vec{BC}| = \sqrt{16+9} = 5$. Тогда

  $$\cos B = \frac{16}{4\cdot5} = 0{,}8 \;\Longrightarrow\; \angle B \approx 36{,}9°.$$

  **Угол $C$.** Векторы $\vec{CA} = (0;-3)$ и $\vec{CB} = (4;-3)$, произведение $0+9 = 9$, длины $3$ и $5$:

  $$\cos C = \frac{9}{3\cdot5} = 0{,}6 \;\Longrightarrow\; \angle C \approx 53{,}1°.$$

  Проверка: $90° + 36{,}9° + 53{,}1° = 180°$. Сумма углов сошлась — значит, ошибки нигде нет.
</WorkedExample>

<WorkedExample title="Подбор координаты">
  При каком $t$ векторы $\vec m(t;3)$ и $\vec n(4;-2)$ перпендикулярны?

  Условие перпендикулярности — равенство нулю произведения:

  $$4t + 3\cdot(-2) = 0 \;\Longrightarrow\; 4t = 6 \;\Longrightarrow\; t = 1{,}5.$$

  Проверка: $\vec m(1{,}5;3)$ и $\vec n(4;-2)$ дают $6-6=0$. Верно.
</WorkedExample>

<Concept type="mistake" title="Четыре ловушки">
  **Ответ считают вектором.** $\vec a\cdot\vec b$ — это число. Записывать его в скобках как пару координат нельзя.

  **Перемножают «крест-накрест».** В формуле стоит $x_1x_2+y_1y_2$, а не $x_1y_2+y_1x_2$.

  **Из нуля делают вывод о нулевом векторе.** Равенство $\vec a\cdot\vec b=0$ при ненулевых векторах означает перпендикулярность, а не то, что один из них нулевой.

  **Сокращают на вектор.** Из $\vec a\cdot\vec b = \vec a\cdot\vec c$ не следует $\vec b = \vec c$: например, при $\vec a(1;0)$, $\vec b(2;5)$ и $\vec c(2;-3)$ оба произведения равны $2$, а векторы разные.
</Concept>

## Практика

1. Найди $\vec a\cdot\vec b$ для $\vec a(3;-2)$ и $\vec b(-1;4)$.
2. Найди $\vec a\cdot\vec a$ и $|\vec a|$ для $\vec a(-6;8)$.
3. Перпендикулярны ли векторы $\vec m(2;-1)$ и $\vec n(3;6)$?
4. При каком $t$ векторы $(t;3)$ и $(4;-2)$ перпендикулярны?
5. Найди угол между $\vec a(1;0)$ и $\vec b(1;1)$.
6. Найди угол между $\vec a(2;2)$ и $\vec b(-3;0)$.
7. Найди угол между $\vec a(1;2)$ и $\vec b(3;1)$.
8. Известно, что $|\vec a| = 3$, $|\vec b| = 5$, а угол между ними равен $60°$. Найди $\vec a\cdot\vec b$.
9. Найди все углы треугольника с вершинами $A(1;2)$, $B(5;2)$, $C(1;5)$.
10. Найди угол между $\vec a(4;3)$ и $\vec b(3;-4)$.
11. В прямоугольнике $A(0;0)$, $B(8;0)$, $C(8;6)$, $D(0;6)$ найди косинус угла между векторами $\vec{AC}$ и $\vec{BD}$.
12. Докажи, что четырёхугольник $A(0;0)$, $B(4;3)$, $C(1;7)$, $D(-3;4)$ — квадрат.

<details>
  <summary>Ответы и пояснения</summary>

  1. $3\cdot(-1)+(-2)\cdot4 = -3-8 = -11$. Угол тупой.
  2. $\vec a\cdot\vec a = 36+64 = 100$, поэтому $|\vec a| = 10$.
  3. $2\cdot3+(-1)\cdot6 = 6-6 = 0$ — да, перпендикулярны.
  4. $4t-6=0$, значит $t = 1{,}5$.
  5. $\vec a\cdot\vec b = 1$, $|\vec a| = 1$, $|\vec b| = \sqrt2$; $\cos\alpha = \dfrac{1}{\sqrt2}$, поэтому $\alpha = 45°$.
  6. $\vec a\cdot\vec b = -6$, $|\vec a| = 2\sqrt2$, $|\vec b| = 3$; $\cos\alpha = \dfrac{-6}{6\sqrt2} = -\dfrac{1}{\sqrt2}$, поэтому $\alpha = 135°$.
  7. $\cos\alpha = \dfrac{5}{\sqrt5\cdot\sqrt{10}} = \dfrac{\sqrt2}{2}$, значит $\alpha = 45°$.
  8. $\vec a\cdot\vec b = 3\cdot5\cdot\cos 60° = 15\cdot0{,}5 = 7{,}5$.
  9. $\angle A = 90°$, $\angle B \approx 36{,}9°$ (косинус $0{,}8$), $\angle C \approx 53{,}1°$ (косинус $0{,}6$).
  10. $\vec a\cdot\vec b = 12-12 = 0$, поэтому угол равен $90°$.
  11. $\vec{AC} = (8;6)$, $\vec{BD} = (-8;6)$; произведение $-64+36 = -28$, длины по $10$, значит $\cos\alpha = -0{,}28$.
  12. Стороны: $\vec{AB} = (4;3)$, $\vec{BC} = (-3;4)$, $\vec{CD} = (-4;-3)$, $\vec{DA} = (3;-4)$ — все длины равны $5$. Соседние стороны перпендикулярны: $\vec{AB}\cdot\vec{BC} = -12+12 = 0$. Равные стороны и прямые углы дают квадрат.

</details>

## Итог

- Скалярное произведение — число: по определению $|\vec a||\vec b|\cos\alpha$, в координатах $x_1x_2+y_1y_2$.
- Знак произведения читается без вычисления угла: плюс — острый, ноль — прямой, минус — тупой.
- Равенство нулю — рабочий признак перпендикулярности, который не требует чертежа.
- Формула $\cos\alpha = \dfrac{\vec a\cdot\vec b}{|\vec a||\vec b|}$ даёт сам угол, а сумма углов треугольника служит бесплатной проверкой.

Мы научились считать длины и углы по координатам. В следующем уроке посмотрим на преобразования, которые эти длины и углы **не меняют**, — на движения плоскости.

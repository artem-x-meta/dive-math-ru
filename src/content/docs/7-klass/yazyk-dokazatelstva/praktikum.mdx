## Как устроено доказательство

<Concept type="remember" title="Чек-лист доказательства">
  1. Записал **Дано** — только то, что действительно дано, без «видно из чертежа».
  2. Записал **Доказать** — одно конкретное утверждение.
  3. Каждый шаг сопровождается ссылкой: определение, аксиома или теорема с номером.
  4. При равенстве треугольников проверил порядок букв: соответственные элементы должны стоять на одинаковых местах.
  5. В конце — то самое утверждение, которое требовалось, и знак $\blacksquare$.
</Concept>

<WorkedExample title="Три шага: параллельность → равенство треугольников → середина">
  **Дано:** $AB \parallel CD$; отрезки $AD$ и $BC$ пересекаются в точке $O$; $AB = CD$.

  **Доказать:** $AO = OD$.

  **Доказательство.** Рассмотрим треугольники $ABO$ и $DCO$.

  1. $AB = CD$ — по условию.
  2. $\angle BAO = \angle CDO$ — накрест лежащие углы при параллельных прямых $AB$ и $CD$ и секущей $AD$ (теорема 8).
  3. $\angle ABO = \angle DCO$ — накрест лежащие углы при тех же параллельных прямых и секущей $BC$ (теорема 8).

  Сторона $AB$ и прилежащие к ней углы $A$ и $B$ равны стороне $DC$ и прилежащим к ней углам $D$ и $C$, поэтому по признаку II

  $$\triangle ABO = \triangle DCO.$$

  Соответственные стороны равных треугольников равны, а стороне $AO$ соответствует сторона $DO$. Значит $AO = OD$. $\blacksquare$
</WorkedExample>

<WorkedExample title="Внешний угол и равнобедренность вместе">
  В равнобедренном треугольнике $ABC$ с основанием $AB$ внешний угол при вершине $C$ равен $130°$. Найдём все углы треугольника.

  Внутренний угол при вершине $C$ смежен с внешним:

  $$\angle C = 180° - 130° = 50°.$$

  Углы при основании равны, и по следствию из теоремы 9

  $$\angle A = \angle B = \frac{180° - 50°}{2} = 65°.$$

  Проверка двумя способами: сумма углов $65° + 65° + 50° = 180°$, а внешний угол по теореме 10 равен $65° + 65° = 130°$ — как и было дано. $\blacksquare$
</WorkedExample>

## Итоговый набор задач

1. Один из смежных углов на $54°$ больше другого. Найди оба.
2. При пересечении двух прямых один из углов в $5$ раз меньше смежного с ним. Найди все четыре угла.
3. При параллельных прямых один из односторонних углов вдвое больше другого. Найди эти углы.
4. Накрест лежащие углы при секущей равны $47°$ и $47°$. Что можно сказать о прямых и почему?
5. В треугольнике $\angle A = 3\angle B$, а $\angle C = 80°$. Найди $\angle A$ и $\angle B$.
6. Внешний угол треугольника при вершине $A$ равен $108°$, а $\angle B = 47°$. Найди $\angle A$ и $\angle C$.
7. Периметр равнобедренного треугольника равен $46$ см, основание — $16$ см. Найди боковую сторону.
8. Боковая сторона равнобедренного треугольника равна $13$ см, периметр — $34$ см. Найди основание.
9. В равнобедренном треугольнике $ABC$ с основанием $AB$ угол $C$ равен $44°$. Найди $\angle A$ и $\angle B$.
10. Отрезки $AB$ и $CD$ пересекаются в точке $O$ — середине каждого из них. Докажи, что $AC \parallel BD$.
11. В треугольнике $ABC$ известно, что $\angle B = 50°$, $\angle C = 70°$, а $AD$ — биссектриса угла $A$, где точка $D$ лежит на $BC$. Найди $\angle ADB$.
12. Докажи: если два внешних угла треугольника равны, то треугольник равнобедренный.

<details>
  <summary>Ответы, ссылки на теоремы и проверки</summary>

  1. $x + (x + 54°) = 180°$, $2x = 126°$, $x = 63°$; углы $63°$ и $117°$ (теорема 1). Проверка: $63 + 117 = 180$.
  2. $x + 5x = 180°$, $x = 30°$; углы $30°$, $150°$, $30°$, $150°$ (теоремы 1 и 2). Сумма всех четырёх равна $360°$.
  3. $x + 2x = 180°$, $x = 60°$; углы $60°$ и $120°$ (следствие из теоремы 8).
  4. Прямые параллельны по признаку из теоремы 7: равные накрест лежащие углы.
  5. $\angle A + \angle B = 180° - 80° = 100°$; $3\angle B + \angle B = 100°$, $\angle B = 25°$, $\angle A = 75°$. Проверка: $75 + 25 + 80 = 180$.
  6. $\angle A = 180° - 108° = 72°$ (смежные); $\angle C = 108° - 47° = 61°$ (теорема 10). Проверка: $72 + 47 + 61 = 180$.
  7. $(46 - 16) : 2 = 15$ см.
  8. $34 - 2 \cdot 13 = 8$ см.
  9. $\angle A = \angle B = (180° - 44°) : 2 = 68°$. Проверка: $68 + 68 + 44 = 180$.
  10. В треугольниках $AOC$ и $BOD$: $AO = OB$, $CO = OD$ по условию, $\angle AOC = \angle BOD$ как вертикальные (теорема 2). По признаку I треугольники равны, поэтому $\angle OAC = \angle OBD$. Это накрест лежащие углы при прямых $AC$ и $BD$ и секущей $AB$, значит по теореме 7 $AC \parallel BD$.
  11. $\angle A = 180° - 50° - 70° = 60°$, поэтому $\angle BAD = 30°$. В треугольнике $ABD$: $\angle ADB = 180° - 50° - 30° = 100°$. Проверка через внешний угол: $\angle ADB$ — внешний угол треугольника $ADC$ при вершине $D$, и он равен $\angle C + \angle DAC = 70° + 30° = 100°$.
  12. Пусть внешние углы при вершинах $A$ и $B$ равны. Смежные с ними внутренние углы равны $180°$ минус одно и то же число, значит $\angle A = \angle B$. По теореме 5 треугольник равнобедренный с основанием $AB$.

</details>

## Рефлексия

1. Какая теорема встречалась в твоих доказательствах чаще всего?
2. В каком месте ты чуть не сослался на «видно из чертежа» вместо теоремы?
3. Какие теоремы главы обязательно опираются на аксиому параллельных, а какие обошлись без неё?

Возможные ответы: чаще всего работают теоремы 1 и 2 про смежные и вертикальные углы — они нужны почти в каждом чертеже; на аксиому параллельных опираются теорема 8 и всё, что из неё выведено, включая сумму углов треугольника и внешний угол; признаки равенства треугольников, свойства равнобедренного треугольника и признаки параллельности аксиому параллельных не используют.

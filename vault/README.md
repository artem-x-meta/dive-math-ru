# Ныряем в математику — граф понятий

Это хранилище Obsidian поверх книги. Оно не копия учебника, а **карта связей**: что от чего зависит, где понятие вводится и где потом работает.

## Что открыть первым

- [[Карта книги]] — точка входа, шесть содержательных линий.
- [[Указатель уроков]] — точные имена всех заметок об уроках.

## Как всё устроено

**`ponyatiya/`** — заметки о понятиях, написаны вручную. Одно понятие — один файл. Внутри: определение, зачем понятие нужно, связи с другими понятиями и ссылки на уроки, где оно вводится и используется.

**`uroki/`** — карточки уроков, генерируются автоматически из MDX командой `npm run vault`. Править их руками бессмысленно: следующий запуск перезапишет. В карточке нет текста урока — только название, цели, лаборатории и ссылка на страницу книги.

## Почему так

Текст урока живёт ровно в одном месте — в `src/content/docs/`. Если скопировать его сюда, через месяц будет два расходящихся источника правды. Поэтому заметки об уроках короткие и производные, а ценность хранилища — в ручных связях между понятиями, которых в линейной книге не видно.

## Что даёт граф

- **Обратные ссылки.** Открой понятие — увидишь все уроки, где оно работает. Книга на такой вопрос не отвечает.
- **Граф целиком.** Видно, как линия тянется через шесть лет: отношение → пропорция → линейная функция → производная.
- **Аудит.** Висячая ссылка означает, что понятие используется, но нигде не определено. Тест `tests/vault.test.ts` такие случаи находит.

## Ссылки на страницы книги

Карточки уроков ссылаются на `http://localhost:4321` — адрес локального `npm run dev`. Для другого адреса пересобери хранилище с переменной окружения:

```sh
SITE_URL=https://math.example.org npm run vault
```

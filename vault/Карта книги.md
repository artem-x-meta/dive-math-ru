# Карта книги

Шесть содержательных линий проходят через все шесть лет. Ниже — по несколько опорных понятий каждой линии в том порядке, в каком они появляются; остальные видны в графе как соседи.

Полный список уроков — в заметке [[Указатель уроков]].

## Числа

Как устроены сами числа и действия с ними.

[[Делитель]] → [[Простое число]] → [[Наибольший общий делитель]] → [[Дробь]] → [[Отношение]] → [[Процент]] → [[Целое число]] → [[Степень]] → [[Рациональное число]] → [[Корень]] → [[Иррациональное число]] → [[Действительное число]] → [[Степень с рациональным показателем]] → [[Логарифм]]

## Алгебра

Буква вместо числа, преобразование и решение.

[[Переменная]] → [[Буквенное выражение]] → [[Формула]] → [[Тождество]] → [[Многочлен]] → [[Линейное уравнение]] → [[Система линейных уравнений]] → [[Алгебраическая дробь]] → [[Квадратное уравнение]] → [[Дискриминант]] → [[Теорема Виета]] → [[Неравенство]] → [[Квадратное неравенство]] → [[Иррациональное уравнение]]

## Функции

## Рассуждение

Самая сквозная линия: почти без своих глав, зато во всех остальных.

[[Определение]] → [[Контрпример]] → [[Аксиома]] → [[Теорема]] → [[Доказательство]] → [[Доказательство от противного]] → [[Множество]] → [[Область допустимых значений]] → [[Равносильность]] → [[Следствие]] → [[Квантор]] → [[Математическая модель]] → [[Выбор метода решения]]

## Что смотреть в графе

Включи вид графа и подсвети тег линии — станет видно, где линии сходятся. Самые интересные узлы книги те, куда приходят стрелки сразу из нескольких линий:

- [[Координатная плоскость]] — геометрия встречается с функциями;
- [[Теорема Пифагора]] — геометрия с числами (иррациональность появляется именно отсюда);
- [[Производная]] — функции с рассуждением о предельном переходе;
- [[Сочетание]] — данные с алгеброй;
- [[Область допустимых значений]] — алгебра с рассуждением.

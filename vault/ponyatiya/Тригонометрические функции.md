# Тригонометрические функции

Функции $y=\sin x$, $y=\cos x$, $y=\operatorname{tg} x$ числового аргумента: синус и косинус — координаты точки [[Единичная окружность|единичной окружности]], тангенс — их отношение.

## Зачем

Это первые функции книги, у которых значения повторяются: развернув движение точки по окружности в линию, получаем синусоиду. Их паспорт стоит помнить целиком — $D$ и $E$, [[Периодичность|период]], [[Чётность функции|чётность]], нули:

- $\sin x$: определён всюду, значения $[-1;1]$, период $2\pi$, нечётный, нули $\pi n$;
- $\cos x$: то же самое, но чётный, нули $\frac\pi2+\pi n$;
- $\operatorname{tg} x$: не определён при $x=\frac\pi2+\pi n$, значения — вся прямая, период $\pi$, нечётный, есть вертикальные асимптоты.

Ими описывают всё колебательное — колесо обозрения, маятник, суточный ход температуры.

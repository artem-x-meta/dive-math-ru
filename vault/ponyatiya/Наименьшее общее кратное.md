# Наименьшее общее кратное

Наименьшее положительное число, которое делится на каждое из данных; запись $\operatorname{НОК}(a,b)$. По разложениям: берут все простые множители, каждый в наибольшей встречающейся степени.

## Зачем

НОК отвечает на вопрос «когда циклы совпадут снова» — встреча автобусов, совпадение расписаний. И он же даёт наименьший [[Общий знаменатель]]: без него сложение [[Дробь|дробей]] превращается в работу с огромными числами.

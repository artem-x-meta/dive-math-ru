# Скалярное произведение

Число $\vec a \cdot \vec b = |\vec a||\vec b|\cos\varphi$; в координатах — $x_1x_2 + y_1y_2$. Результат умножения двух векторов — не вектор, а число.

## Зачем

Равенство двух формул — рабочий инструмент: правая часть считается по координатам без всякого угла, левая содержит косинус, значит угол находится вычислением. Частный случай важнее общего: скалярное произведение равно нулю тогда и только тогда, когда векторы перпендикулярны, — так [[Перпендикуляр|перпендикулярность]] становится арифметической проверкой. В пространстве это единственный удобный способ измерить угол между [[Аксиомы стереометрии|скрещивающимися прямыми]] и между плоскостями через векторы нормалей.

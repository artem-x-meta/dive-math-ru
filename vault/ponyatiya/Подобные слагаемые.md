# Подобные слагаемые

Слагаемые с одинаковой буквенной частью. Складываются их **коэффициенты**, буквенная часть сохраняется: $ax+bx=(a+b)x$.

## Зачем

Приведение подобных — шаг, которым заканчивается почти любое преобразование: после раскрытия скобок запись всегда сжимают. Из него же вырастает стандартный вид многочлена, где подобных членов уже нет по определению.

# Переменная

Буква, обозначающая число, которое может принимать разные значения. С неё запись перестаёт быть одним расчётом и становится планом сразу для всех значений.

## Зачем

Без переменной невозможны ни формула, ни уравнение, ни функция: вся алгебра — это разговор о числе, которое ещё не названо. Буква обозначает число, а не единицу измерения и не предмет.

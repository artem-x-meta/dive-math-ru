# Правило произведения

Если выбор делают за несколько шагов и число вариантов очередного шага не зависит от предыдущего, то всего вариантов $N=n_1\cdot n_2\cdot\ldots\cdot n_k$.

## Зачем

Это способ сосчитать варианты, не выписывая их: [[Дерево вариантов|дерево]] можно уже не рисовать. Парное к нему **правило суммы** работает, когда выбирают ровно из одного из непересекающихся наборов: тогда числа складывают. Слово-подсказка для произведения — «и», для суммы — «или»; в одной задаче они обычно работают вместе: внутри случая умножаем, между случаями складываем.

Из правила произведения выводятся все формулы комбинаторики — [[Перестановка|перестановки]], [[Сочетание|сочетания]], число подмножеств $2^n$. В вероятностях оно превращается в умножение вдоль пути [[Дерево испытаний|дерева испытаний]].

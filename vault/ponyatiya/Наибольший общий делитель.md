# Наибольший общий делитель

Самый большой из чисел, делящих оба данных числа без остатка; запись $\operatorname{НОД}(a,b)=d$. По разложениям находится так: общие простые множители берут в наименьшей встречающейся степени.

## Зачем

НОД отвечает на вопрос «какого наибольшего размера может быть одинаковая часть» — максимальное число равных групп, самая крупная плитка без подрезки. Он же полностью сокращает [[Дробь|дробь]]: делённые на НОД числитель и знаменатель становятся взаимно простыми.

# Общий знаменатель

Одинаковый знаменатель, к которому приводят несколько [[Дробь|дробей]], чтобы их доли стали одного размера. Наименьший общий знаменатель — это [[Наименьшее общее кратное|НОК]] исходных знаменателей.

## Зачем

Складывать и сравнивать можно только одинаковые единицы — в этом вся причина, по которой знаменатели не складываются. Приведение к общему знаменателю переводит разные доли в один масштаб, и дальше работа идёт только с числителями. Тот же приём переносится в 8 класс на дроби с буквами.

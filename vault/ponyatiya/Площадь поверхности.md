# Площадь поверхности

Сумма площадей всех граней тела. Боковая поверхность — без оснований, полная — с ними; путать их и есть главная ошибка темы.

## Зачем

Формулы не нужно запоминать, если помнить развёртку: разложи поверхность на плоскость — и объёмная задача станет плоской. У прямой призмы боковая развёртка оказывается прямоугольником, значит $S_{\text{бок}} = P h$; у правильной пирамиды — набором равных треугольников с апофемой в роли высоты, и апофему нельзя подменять высотой самой пирамиды. Тот же приём работает для [[Тело вращения|тел вращения]]: развёртка цилиндра — прямоугольник, конуса — круговой сектор.

# Таблица значений

Список пар «значение переменной — значение выражения», полученный подстановкой чисел в формулу. Каждая строка отвечает на вопрос «что будет, если $x$ равен вот этому».

## Зачем

Таблица — самый ранний способ увидеть зависимость до всяких графиков: по столбцу значений заметно, растёт величина или падает, равномерно или всё быстрее. Позже она становится рабочим инструментом построения: две точки для прямой, пять-семь для параболы, отдельные точки для [[Числовая последовательность|последовательности]].

Второй смысл — контроль допустимости: подставлять можно не всякое число, и отсюда позже вырастает [[Область определения]].

# Квадратное неравенство

Неравенство вида $ax^2+bx+c>0$ (или с другим знаком). Решается по эскизу параболы: нужны только знак $a$ и нули трёхчлена — между нулями знак трёхчлена противоположен знаку $a$, вне нулей совпадает с ним.

## Зачем

Здесь квадратное уравнение перестаёт быть самоцелью: его корни превращаются в границы промежутков. Случаи $D=0$ и $D<0$ дают особые ответы — пустое множество, всю прямую, одну точку или прямую без одной точки; строгий знак нули выкалывает, нестрогий включает.

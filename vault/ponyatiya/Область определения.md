# Область определения

Множество $D(f)$ тех $x$, при которых правило вообще применимо. Парный к нему набор — **множество значений** $E(f)$: все $y$, которые функция действительно принимает.

## Зачем

Половина ошибок в задачах — это ответы, вылезшие за $D(f)$. По формуле область ищут по двум запретам: знаменатель не равен нулю, подкоренное выражение неотрицательно. У [[Обратная пропорциональность|гиперболы]] выпадает нуль, у $\sqrt{x}$ — вся левая полуось, у [[Логарифмическая функция|логарифма]] остаются только положительные числа.

$E(f)$ отвечает на обратный вопрос — какие значения достижимы; у [[Показательная функция|показательной функции]] это только положительные числа, у синуса — отрезок $[-1;1]$. При переходе к [[Обратная функция|обратной функции]] два множества меняются ролями.

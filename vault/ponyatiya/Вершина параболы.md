# Вершина параболы

Точка $(x_0;y_0)$, где $x_0=-\dfrac b{2a}$, а $y_0=y(x_0)$. Прямая $x=x_0$ — ось симметрии [[Парабола|параболы]]: значения функции встречаются парами по обе стороны от неё.

## Зачем

В вершине стоит наименьшее значение функции при $a>0$ и наибольшее при $a<0$ — то есть одна формула отвечает на все задачи об оптимуме для квадратичной модели. Она же задаёт множество значений и границу между промежутками возрастания и убывания.

Ордината вершины **не равна** $c$: формула даёт только абсциссу, значение получают подстановкой. В 11 классе вершина оказывается частным случаем: условие $y'=0$ для $y=ax^2+bx+c$ даёт ровно $x=-\frac b{2a}$, а вершина — [[Экстремум|точкой экстремума]].

# Действительное число

[[Рациональное число|Рациональные]] и [[Иррациональное число|иррациональные]] числа вместе. Их главное свойство — полнота: каждому действительному числу отвечает точка [[Координатная прямая|координатной прямой]], и каждой точке — число, без просветов.

## Зачем

Это финальное расширение числовой системы в школьном курсе: цепочка натуральные → [[Целое число|целые]] → рациональные → действительные здесь заканчивается. Полнота — то условие, без которого не имеют смысла ни [[Область определения|область определения]] функции на промежутке, ни предел, ни [[Производная]], ни [[Интеграл]].

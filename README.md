# Ныряем в математику

**Читать книгу: [artem-x-meta.github.io/dive-math-ru](https://artem-x-meta.github.io/dive-math-ru/)**

Интерактивная русскоязычная онлайн-книга по математике для 6–11 классов. Проект берёт у *Dive Into Deep Learning* идею связного учебника, где объяснение, формулы, визуальный эксперимент и практика находятся на одной странице.

## Что уже работает

Книга написана целиком: **33 главы за 6–11 классы**, 243 страницы, 84 интерактивные лаборатории.

- книжная оболочка с поиском, оглавлением, светлой/тёмной темой и адаптивной навигацией;
- карта программы 6–11 классов и страница-обзор для каждого года;
- **6 класс** — делимость, дроби, отношения и проценты, числа со знаком, буквы и формулы, наглядная геометрия, данные и перебор;
- **7 класс** — рациональные числа и степени, алгебраический язык, линейные модели, язык доказательства, данные и случайность;
- **8 класс** — действительные числа, алгебраические дроби, квадратные уравнения, функции и неравенства, подобие и окружность, вероятностные деревья;
- **9 класс** — уравнения и системы, квадратичная функция, последовательности, геометрический синтез, векторы и движения, комбинаторика;
- **10 класс** — общий язык функций, тригонометрия, уравнения и логика, пространство, многогранники и сечения, условная вероятность;
- **11 класс** — экспонента и логарифм, производная, интеграл, тела вращения, векторы в пространстве, статистическое мышление;
- задания с адресной обратной связью, тренажёры и локальная отметка прогресса;
- формулы KaTeX, доступные SVG-схемы и клавиатурные элементы управления.

Вся математика лабораторий вычисляется в `src/lib/` и покрыта тестами (1400 тестов): чертежи строятся по вычисленным координатам, развёртки действительно складываются, а тесты пересчитывают ответы, напечатанные в уроках.

## Запуск

```sh
npm install
npm run dev
```

Astro покажет локальный адрес, обычно `http://localhost:4321`.

## Проверка

```sh
npm run check
npm test
npm run build
npm run preview
```

Для production-деплоя передайте публичный адрес в `SITE_URL` (например, `https://math.example.org`). Astro использует его для canonical URL и sitemap; локальная сборка без домена намеренно пропускает sitemap.

## Публикация

Книга живёт по адресу <https://artem-x-meta.github.io/dive-math-ru/> и публикуется автоматически при каждом пуше в `main` — workflow `.github/workflows/deploy.yml` сначала гоняет `astro check` и тесты и только потом собирает и выкладывает. Сломанная версия на сайт не уедет: публикация зависит от сборки, а сборка — от проверок.

Pages отдаёт проект по подпути, поэтому сборка принимает ещё одну переменную:

```sh
SITE_URL=https://artem-x-meta.github.io BASE_PATH=/dive-math-ru npm run build
```

Ссылки в исходниках при этом остаются корневыми (`/6-klass/delimost/`) — так их проверяет `tests/content.test.ts` и так работает `npm run dev`. Префикс подставляется на сборке: разметку обрабатывает `scripts/remark-base-links.mjs`, а компоненты, которые собирают `href` сами, пользуются `withBase()` из `src/lib/basePath.ts`. Без `BASE_PATH` оба механизма ничего не делают, поэтому деплой в корень домена работает без изменений.

Исключение — кнопки в hero на главной: Starlight не подставляет базовый путь во frontmatter, поэтому там ссылки записаны относительными.

## Архитектура

```text
src/content/docs/       MDX-страницы книги
src/components/         Astro- и React-компоненты уроков
src/lib/                проверяемая математическая логика
src/styles/custom.css   тема и дизайн-система
src/assets/             обрабатываемые SVG-иллюстрации
tests/                  unit-тесты математики и связности
scripts/                генератор Obsidian-хранилища
vault/                  граф понятий для Obsidian
```

## Граф понятий (Obsidian)

Каталог `vault/` — хранилище Obsidian поверх книги: 166 заметок о понятиях со связями через все шесть лет плюс автогенерируемые карточки 233 уроков. Текст уроков туда не копируется, только смысловые связи и ссылки на страницы книги.

```sh
npm run vault                                   # пересобрать карточки уроков
SITE_URL=https://math.example.org npm run vault # со ссылками на публичный адрес
```

Заметки о понятиях в `vault/ponyatiya/` написаны вручную и генератором не трогаются. `tests/vault.test.ts` следит, чтобы ссылки не висели в пустоте: висячая `[[ссылка]]` означает, что понятие используется, но нигде не определено. Подробности — в `vault/README.md`.

Astro и Starlight отвечают за быстрые статические страницы, навигацию и поиск. React подключается точечно только к интерактивным лабораториям. Точные математические рисунки создаются в SVG.

## Шаблон урока

Новый урок должен содержать:

1. вопрос или ситуацию;
2. прогноз до вычислений;
3. управляемый эксперимент;
4. точное определение или правило;
5. разобранный пример;
6. короткую проверку;
7. типичную ошибку;
8. практику с ответами;
9. итог и связь со следующей темой.

Контент не следует добавлять массово без математической вычитки: один проверенный маршрут полезнее десятка страниц-заглушек.

Правила, которые легко нарушить и трудно заметить:

- в YAML-фронтматтере `description` двоеточие без кавычек ломает сборку;
- многострочный блок `$$...$$` внутри JSX-компонента (`Concept`, `WorkedExample`) ломает MDX — такие формулы пишутся в одну строку;
- в MDX атрибуты SVG пишутся в kebab-case (`text-anchor`), в `.tsx` — в camelCase;
- новая страница должна попасть в сайдбар `astro.config.mjs` и в список маршрутов `tests/content.test.ts`;
- каждый `lessonId` урока обязан встречаться в `CourseProgress` на входе в главу — это проверяется тестом.
